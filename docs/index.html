What JARVAS can do

Tools are exposed directly to your MCP-compatible AI client.

MC

Mouse & keyboard

Move and click, drag, scroll, type text, press keys, and send hotkeys.

WIN

Windows & apps

List windows, focus, minimize, maximize, move, launch apps, and close them safely.

PNG

Screenshots

Capture the full screen or a specific window as a PNG image.

UIA

UI Automation

Find elements by name or role, then click them without guessing pixels.

TXT

Clipboard

Read and write plain text on the Windows clipboard.

LOG

Action log

See what JARVAS did via stderr, jarvas.log, or the get_action_log tool.

Get running in minutes

JARVAS does not open a window. Your AI client starts it in the background.

Download the executableSave jarvas-server.exe somewhere permanent, such as your Downloads folder.
Add the MCP configPaste one of the configs below into your AI client and replace the path with your real .exe location.
Restart your AI clientConfirm the jarvas server is connected, then ask it to take a screenshot or list windows.
Keep controlPress Ctrl+Shift+J any time for an emergency stop.

Configuration

Use the config that matches your AI client.

OpenCode

opencode.json
{
  "$schema": "opencode.ai/config.json",
  "mcp": {
    "servers": {
      "jarvas": {
        "type": "local",
        "command": ["C:/Users/YOU/Downloads/jarvas-server.exe"],
        "environment": {
          "JARVAS_ACTION_DELAY_MS": "150"
        }
      }
    }
  }
}

Claude Desktop, Cursor, and similar MCP clients

mcpServers config
{
  "mcpServers": {
    "jarvas": {
      "command": "C:/Users/YOU/Downloads/jarvas-server.exe",
      "args": [],
      "env": {
        "JARVAS_ACTION_DELAY_MS": "150"
      }
    }
  }
}
Note: Browser-only chatbots cannot control your PC unless they support local MCP servers. Use an MCP-compatible desktop/CLI client.

Built with safety controls

PC control is powerful, so JARVAS includes guardrails.

Emergency stop

Ctrl+Shift+J blocks all further actions until the server restarts.

Destructive confirmation

Closing windows or apps requires confirm=true.

Action delay

A default 150 ms pause between actions keeps control deliberate.
